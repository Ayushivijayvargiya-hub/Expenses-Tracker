# FinTrack Features Guide

## 🌓 Dark Mode vs Light Mode

### How to Toggle:

- Look at sidebar (left side of screen)
- Scroll to bottom
- Click the moon (🌙) or sun (☀️) icon
- Instant theme change!

### Visual Differences:

#### Light Mode:

```

│  ☀️ LIGHT MODE                     │
```

## 🎯 Understanding AI Recommendations

### Alert Levels:

| Change    | Icon | Color  | Severity  | Message                               |
| --------- | ---- | ------ | --------- | ------------------------------------- |
| > 30% ↑   | 🚨   | Red    | Critical  | Significant increase! Review spending |
| 15-30% ↑  | ⚠️   | Orange | Warning   | Moderate increase. Monitor closely    |
| 5-15% ↑   | 📈   | Yellow | Caution   | Slight increase. Keep an eye on it    |
| -5% to 5% | ➡️   | Blue   | Normal    | Stable spending. All good!            |
| < -5% ↓   | 📉   | Green  | Good      | Good progress!                        |
| < -20% ↓  | 🎉   | Green  | Excellent | Excellent reduction!                  |

## 🆘 Troubleshooting

### Dark Mode Not Working?

```
✓ Check if theme toggle is clicked
✓ Refresh the page
✓ Clear browser cache
✓ Check localStorage (should have theme preference)
```

### No AI Insights Showing?

```
✓ Add some transactions first
✓ Wait a few seconds (it's loading)
✓ Check you have expense transactions
✓ Try refreshing the page
```

### Wrong Comparison?

```
✓ Check transaction dates
✓ Make sure expenses are marked as "expense" type
✓ Verify transactions are in correct months
✓ Dates should be in YYYY-MM-DD format
```
